تجربة أذكى وأسرع وأسهل

الجديد للمستخدم

  • تسجيل صوتي أطول: تقدر تتكلم لفترة أطول، والتسجيل يحاول يكمل تلقائيًا لو المتصفح أنهى جلسة الكلام مؤقتًا.
  • عداد وقت حي: تشوف مدة تجهيز الإجابة من لحظة الإرسال لحد اكتمالها.
  • إجابات أوضح: تحسين طريقة فهم السؤال والقيود المطلوبة قبل تكوين الرد النهائي.
  • بحث أفضل: عند الحاجة لمعلومات حديثة، النتائج تُجمع وتُرتب بشكل أوضح مع مصادر منفصلة عن نص الإجابة.
  • محادثة أكثر ترابطًا: PathPilot يفهم المتابعة والتعديل وإعادة المحاولة بصورة أفضل داخل نفس الجلسة.
  • إيقاف وإعادة المحاولة: تقدر توقف الطلب الجاري، تعدل سؤالك، أو تعيد إنشاء الإجابة بسهولة.
  • بحث شامل داخل التطبيق: الوصول للأدوات والصفحات والإعدادات والنتائج السابقة أصبح أسرع.
  • تجربة صوتية أفضل: إدخال صوتي وقراءة الإجابة بصوت عند دعم الجهاز.

تحسين الشكل وسهولة الاستخدام

  • واجهة أكثر عمقًا وتنظيمًا مع حركة خفيفة لا تعطل القراءة.
  • المصادر تظهر في مساحة مستقلة بدل زحمة الروابط داخل الإجابة.
  • حالة التجهيز أصبحت أوضح أثناء انتظار الإجابة.
  • تحسين استخدام الموبايل ولوحة المفاتيح والاختصارات.
  • إمكانية تثبيت الطلبات المهمة والرجوع للمحادثات والبحث بينها.
  • تحسين التبديل بين العربية والإنجليزية عبر أجزاء الواجهة.

اعتمادية وأمان أعلى

  • تحسين حماية الحسابات والطلبات الحساسة.
  • تقليل فرص إساءة استخدام المدخلات أو المحتوى غير الموثوق.
  • تحسين التعامل مع الضغط والأخطاء المؤقتة بدل تعطيل التجربة بالكامل.
  • إمكانية إيقاف الوظائف الحساسة مؤقتًا بواسطة الإدارة عند وجود حالة طارئة.
  • مراجعات واختبارات مستمرة قبل وصول التحديثات للمستخدم.
الفايدة: تجربة أسرع وأنظف، ردود أكثر ترابطًا، تحكم أكبر أثناء الاستخدام، وبنية أمان واعتمادية أقوى من غير ما يحتاج المستخدم يعرف أي تفاصيل تقنية داخلية.
لأسباب تتعلق بالأمان وحماية المنتج، سجل التحديثات العام لا يعرض أسماء الخدمات الداخلية أو المفاتيح أو تفاصيل البنية أو آليات الحماية الدقيقة.

الحسابات والاسترجاع والبحث والوضع المحلي

  • إنشاء حساب وتفعيل البريد بسهولة.
  • استعادة كلمة المرور برابط آمن ومؤقت.
  • تحسين تسليم رسائل الحساب المهمة.
  • دعم البحث بالمصادر عندما يحتاج السؤال معلومات حديثة.
  • وضع محلي اختياري يساعد على استمرار بعض الوظائف عند عدم توفر الخدمة الحية.
  • تحسين المعرفة المحلية وطريقة تحليل المشكلات والقرارات والخطط.
  • تطوير أدوات الإدارة والمراقبة وحماية حسابات الصلاحيات العالية.
الفايدة: حساب أكثر اكتمالًا، استرجاع أسهل، تجربة أكثر استمرارية، وطبقات حماية أفضل للمستخدم والإدارة.
